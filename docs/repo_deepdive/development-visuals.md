## 树怎样读

理论根系连接六个分析家族，再分为二十四条阅读支路和具体方法叶片。枝干与叶片逐层生长，方法的展开使用首次公开时间；停止动画仍可浏览完整树冠。

**这不是论文引用血统图。** 枝线表达编辑性的分类归属，不证明方法继承、实现复用或因果贡献。同一方法可能涉及多个家族，图上使用一个主要位置，详情保留源数据中的多家族标签。

图中方法、框架和理论参照与基准、综述、边界记录、公司发布分别标记。首发未确定的发布不制造时间节点，只在完整预览显示其不确定性。修订日不替代首发；早期历史采用明确标注的压缩段，不能把屏幕间距直接解释为研究活动密度。

## 控件与动作

| 动作 | 含义 |
|---|---|
| 重放生长 | 从根系重新进行有限时长的解释性播放 |
| 播放／暂停 | 恢复生长进度或暂停；暂停时可预览完整树冠 |
| 完整树冠 | 直接显示所有记录，不宣称全部具备算法或复现证据 |
| 拖拽／滚轮／加减 | 浏览与缩放；移动端放大后读取密集标签 |
| 适配／复位 | 恢复视角，不重置方法的证据或分类 |
| 横向时间线 | 按首发口径回看记录；未知首发不强行放入日期轴 |
| 点击／键盘选择叶片 | 打开原有方法卡，核对原文、限制和阅读范围 |
| 墨夜 | 在宣纸和墨夜配色之间切换，不改变数据 |

视图隐藏或浏览器标签页不可见时停止播放；减少动态效果偏好下展示完整图。动画表达阅读顺序，不是实验轨迹、网络流量或实测能力增长。

## 扇怎样读

六片扇页依次展开到 180°，每片代表一个更新对象家族。扇面展示该类的经典与近期代表，下面的家族列表提供更多方法及其日期。点击方法仍回到同一份证据卡，不新增一套未经核验的论文解读。

模型训练、任务／环境、记忆／技能、Harness、评价和元改进不构成从低到高的自治阶梯。一个方法可以跨类；普通软件修复、参数学习、评价器更新和改进器自身修订需要分别举证。

## 可维护的实现

- [成长树组件](../../scripts/growth-tree.js)：原生 SVG、有限播放和指针／键盘交互。
- [折扇绘制](../../scripts/method-fan-drawing.js)：扇面、扇骨和代表方法几何。
- [折扇交互](../../scripts/method-fan.js)：逐页展开、家族选择和原有方法卡调用。
- [静态后备图构建](../../scripts/build-development-visuals.mjs)：离线扇面输出；完整树 SVG 同时供 README 和无脚本浏览。
- [交互与证据测试](../../scripts/development.test.mjs)：方法覆盖、复杂分支、有限动画、时间线、漫游／缩放、减少动态效果与全文阅读记录。

选择原生 SVG 的理由是语义节点可聚焦、无需外部框架或字体、可直接输出静态图，并避免把 WebGL 或 3D 装饰变成加载、兼容和可访问性的前提。渐变、阴影、纸色、叶片和扇骨构成立体层次，不声称模拟真实植物或实验过程。
