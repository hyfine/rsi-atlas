## 1. 监督边界

本次会话尝试通过会话列表与历史定位“RSI deepdive documentation and repo creation”。可见列表没有暴露这个原任务，只有当前监督会话；没有向无关任务发送催促消息，也不声称建立了不可见任务的后台监控。

随后直接检查现有成果、补齐仓库入口和专题、核验新稿、实现动态图并验证 GitHub 发布。本文是一套可再次执行的监督协议，不是已经常驻运行的服务。离开会话后没有后台 Agent、定时付费调用或隐形监控。

## 2. 发现的交付缺口与处理原则

| 缺口 | 改进 | 验收标准 |
|---|---|---|
| 仓库入口和阅读顺序缺失 | README、算法手册、近期综述与导航 | 读者从一个入口抵达全部专题 |
| 四个长专题仍在独立笔记目录 | 整合中文正文及原有证据 | 相对链接全部可解析 |
| 代表作表没有反映较新的近期条目 | 统一构建精选方法数据与最新综述 | 真实日期；首发/修订/项目日分开 |
| 图表只有分类/时间交互 | 十个阶段化闭环、状态与冻结边界说明 | 播放、单步、复位、换场景、移动布局实测 |
| 下载与元数据混同全文阅读 | 保留出处与阅读层级 | 不把下载/收录数写成精读数 |
| 本地目录含个人路径、缓存和论文 | 公开发布明确文件清单 | Git 不包含 PDF、未经授权的论文图、密钥、日志和本地路径 |
| 未初始化或推送独立仓库 | hyfine 独立发布、验证远端 HEAD | 本地和 GitHub 主分支 commit 相同 |

## 3. 后续每次更新的循环

```text
检查原任务可见性与工作状态
  -> 读取新增输出，建立有具体位置的缺口清单
  -> 只向正确任务发送有验收条件的反馈
  -> 原始来源核验，区分已读/待读/失败
  -> 更新方法卡、正文与动态图
  -> 运行离线构建、链接和浏览器测试
  -> 检查公开文件清单
  -> 推送并验证远端
```

催促消息应该是“补齐某篇方法的冻结边界，并给出版本/章节证据”，不是无条件重复“继续工作”。如果同一方法没有更强证据，就保留未知项，而不是要求模型补齐猜测。

## 4. 优先级最高的后续研究

1. RSI-Opt 的附录留出访问、逐种子结果及成本重新核对。
2. 对 MetaRSI 做同起点、同预算、轮换晋级验证和最终盲测的复现。
3. 对 Dream-RSI 做离线排名—在线收益关联与支持集外失效实验。
4. 对 CoEvo-RSI 补完整模型—Harness 交叉矩阵与训练预算归因。
5. 建立跨任务、跨模型、跨时间迁移矩阵，不用平均分隐藏退化。
6. 定期查询新稿，但把“检索截点”与“确认最新首发日期”分开。

## 5. 自动检查与人工验收

自动检查覆盖：JSON 必填形状、唯一方法 ID、真实日期范围、近期筛选、章节链接、HTML 自包含、私有路径泄露、Git 文件边界、动画行为、浏览器异常与桌面/移动横向溢出。

人工验收覆盖：文字语义、图的关系语义、作者报告的数值口径、机制冻结边界、视觉可读性、检索盲区。自动测试通过不是论文事实已经全部正确的证明。

## 6. 2026-11-06：家族架构与本地图片缺失修复

原始故障是本地章节以 `../pics/family-e-flow.svg` 引用图，但图只在另一份公开工作区存在，没有同步到笔记图片目录。最初修复通过显式同步完成；随后单源迁移将正文与图片归入同一仓库，不再维护外部镜像。

- 六家族新增独立的**整体思想架构**，与代表方法/参考协议的流程图分开；每类都有 SVG 和可离线打开的 HTML。
- 24 个家族资产和 6 个授权论文图由规范仓库统一构建；外部同步参数已退役，原笔记字节保留在忽略的历史归档中。

## 7. 单源维护与双语时间轴验收

- 原笔记全部 183 个文件按 SHA-256 保全；旧入口退役，旧实现工作树归档并锁定，私有 Cowork 案例只在忽略目录维护。
- 英文首页与 README 提供可见中文切换；首页四篇重点方法与“最新排序”分开。
- 时间轴支持首尾日期包含、以所选结束日回推一年的日历窗口、算法家族/机构泳道；闰日、反向区间与缺失日期有真实浏览器测试。
- 机构依据所引用版本的作者块或官方发布者；同一机构与类型筛选必须匹配同一条关系。未核验与已存在但类型未知是两种状态。
- 两份 CSV 分别对应基础输入与完整合并集合，防止 JSON 已扩充而 CSV 仍停留在旧条目数。
- 微信和指定 OpenReview 入口的验证页面不冒充原文；Flint 的网页显示日、站点发布注释和最早公开日明确分离。
